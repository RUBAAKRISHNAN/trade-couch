# Deploying TradeCore (free tiers): Render + Vercel

```
Browser ──► Vercel  (React app, apps/web)
              │  /api/*  ──rewrite──►  Render web service "trade-couch-api"  ──►  Render Postgres 17
              │                         (engine + API + worker, one process)  ──►  Render Key Value (Redis)
              └─ live updates (Socket.IO) connect straight to Render (Vercel can't proxy WebSockets)
```

Why REST goes through Vercel: the refresh token is an httpOnly `SameSite=Lax` cookie. Calling Render directly from a
`*.vercel.app` page would make it a cross-site cookie and sessions would break. The socket authenticates with the
access token instead, so it can connect to Render directly.

Tested locally in production mode (`DATABASE_URL`, `PORT`, `NODE_ENV=production`, one process): migrations and seed
run, login works, orders fill, about 165 MB of memory — inside Render's 512 MB free plan.

## 1. Render (backend, database, Redis)

1. <https://dashboard.render.com> → **New → Blueprint** → connect GitHub → pick **trade-couch**.
2. Render reads `render.yaml` and shows 3 resources: `trade-couch-api`, `trade-couch-db`, `trade-couch-redis`.
3. It asks for two values:
   - `WEB_ORIGIN`: your Vercel URL (e.g. `https://trade-couch.vercel.app`). If you don't know it yet, enter
     `https://trade-couch.vercel.app` and fix it later under the service's **Environment** tab.
   - `GEMINI_API_KEY`: optional; paste it here (never in the repo) to enable the AI coach.
4. **Apply**. The first deploy takes ~5–10 minutes (install, migrations, demo seed).
5. Check `https://trade-couch-api.onrender.com/api/health` → `{"ok":true,"db":true,"redis":true,…}`.

If Render gives the service a different URL (the name was taken), update the URL in `vercel.json` and
`apps/web/.env.production`, commit and push.

## 2. Vercel (frontend)

1. <https://vercel.com/new> → import **trade-couch**.
2. Leave **Root Directory** as the repository root (`vercel.json` sets the install, build and output).
3. **Deploy**. Then open the URL; log in with a demo account (password `Demo@1234`).
4. If the URL differs from what you gave Render as `WEB_ORIGIN`, update `WEB_ORIGIN` on Render (live updates
   need it).

## Free-tier limits to know

- **Render web service sleeps** after ~15 minutes without traffic; the next visit takes about a minute to wake it,
  and the bots/price feeds pause while it sleeps. Open it a minute before a demo.
- **Render free Postgres expires after 30 days** (check Render's current policy). Before then, upgrade it or move
  the database to a free Neon project and set `DATABASE_URL` on the service.
- The **Gemini free tier** allows only a few requests per minute.

## Production checklist

- [ ] Change or remove the demo accounts before sharing the link widely (all use `Demo@1234`).
- [ ] `JWT_SECRET` is generated by Render — never commit it.
- [ ] Keep `GEMINI_API_KEY` only in Render's environment settings.
